# Built-in source descriptions

The source descriptions (`about_*` in `strings.xml`) are shown on the feeds screen and in the
reader. This file holds the sources for every claim in them, so they can be checked and kept up
to date.

## Rules

* **The same facts for every source:** what it is and when it was founded, who owns or funds it,
  and what its feeds contain. One source doesn't get a fact (or a disclaimer) the others don't.
* **No political-leaning labels,** and none of the words that stand in for them, such as
  independent, critical, pro-business, mainstream, 정론지 or 진보/보수.
* **Only facts that hold for years,** each cited below. No circulation, rankings, awards or
  superlatives ("largest", "first", "most trusted"), even when a source says so itself.
* **Describe the feeds in the app,** not everything the outlet publishes.
* **Check the Korean text against the sources too.** Translating the English text isn't enough.
  Both versions make the same claims, with no adjective in one that's missing from the other.

Reviewed 2026-10-11. Claims marked *(observed)* come from reading the feed, not from a published
source.
